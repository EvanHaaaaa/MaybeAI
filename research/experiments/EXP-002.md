# EXP-002: Hybrid Cognitive Memory & Bounded Prompt Budgeting (`research/experiments/EXP-002.md`)

**Status:** Proposed (Ready for Horizon 1 Execution)  
**Owner:** AGENT 10 (`strat-ai`) / Cognition & Memory Engineering  
**Target Audit Findings:** `[COG-HIGH-002]`, `[COG-HIGH-003]`, `[COG-HIGH-004]`, `[COG-HIGH-005]`, `[COG-MED-002]`, `[COG-MED-003]`, `[COG-MED-004]`

## 1. Problem & Hypothesis

### Problem
1. **300-row semantic blind spot & unsafe re-encoding (`[COG-HIGH-005]`):** `MemoryDatabase.vector_search()` / `avector_search()` only scan `get_recent_memories(limit=300)`, making older memories invisible. Dimension mismatches trigger up to 300 sequential REST API calls inline on a single chat turn and can overwrite 768-d/1536-d vectors with 128-d `hash` fallbacks.
2. **Duplicate `EmbeddingEngine` (`[COG-HIGH-004]`):** `EpisodicMemoryStore` instantiates `EmbeddingEngine` twice, doubling RAM/VRAM when local models load.
3. **Unbounded prompt assembly (`[COG-HIGH-002]`, `[COG-HIGH-003]`, `[COG-MED-004]`):** `MasterPromptBuilder` unconditionally concatenates 11 subsystem directives + full `character.lore` + 16 turns; `is_creator` is dropped on live LLM paths; `MoodEngine.get_temperature_modifier()` is dead code; `max_tokens` diverges (`150` OpenAI vs `800` Gemini).

### Hypothesis
If we:
1. Share a single `EmbeddingEngine` instance, add `embedding_backend` / `embedding_dim` metadata columns to `episodic_memories` (forbidding `hash` overwrite of cloud vectors), and replace the 300-row scan with **`sqlite-vec` (or in-memory `hnswlib` fallback) + FTS5 BM25 Reciprocal Rank Fusion (RRF)** offloaded via `asyncio.to_thread`;
2. Implement **`ContextBudgetManager`** with priority-tiered directive pruning (omitting inactive subsystems like idle `minigame`/`desktop`/`storytelling`), `len(text)//4` token budgeting, and `[CREATOR VERIFIED]` + mood-temperature plumbing;

Then **memory recall at `10,000+` rows will execute in `<= 15 ms` with `>= +15%` `Recall@5` improvement on aged memories, `0` event-loop blocks, and `>= 30%` reduction in average prompt tokens without degrading persona consistency.**

## 2. Experimental Design & Matrix

| Component | Baseline (Control) | Variant A (`sqlite-vec` + RRF) | Variant B (`hnswlib` + RRF Fallback) |
|---|---|---|---|
| **Vector Index** | `LIMIT 300` SQLite fetch + Python cosine | `sqlite-vec` (`vec0` virtual table in `memory.db`) | In-process `hnswlib` index hydrated from SQLite at startup |
| **Lexical Signal** | Separate FTS5 path | SQLite FTS5 BM25 + `sqlite-vec` fused via RRF ($k=60$) | SQLite FTS5 BM25 + `hnswlib` fused via RRF ($k=60$) |
| **Local Embedder** | `hash` (128-d) or Gemini/OpenAI | `FastEmbed` (`bge-small-en-v1.5` 384-d CPU ONNX) / Gemini | `FastEmbed` (384-d CPU ONNX) / Gemini |
| **Prompt Assembly** | Unbounded `MasterPromptBuilder` | `ContextBudgetManager` (2,000-token ceiling for local 4K/8K, 4,000-token for cloud) | `ContextBudgetManager` (same) |

### Independent Variables
- Corpus size: `300`, `2,500`, and `10,000` episodic memory rows (`MaybeAI-Memory-Bench-v1`).
- Query set: `100` queries (exact entity names, paraphrased events, inside jokes, and facts placed at row indices `301..10,000`).
- Active subsystem count: `2` active (chat + mood) vs `6` active (chat + mood + MC + vision + collab + goal).

### Dependent Metrics
1. **Retrieval Quality:** `Recall@5` and `MRR@5` overall and on aged memories (index `> 300`).
2. **Query Latency (ms):** p50 and p95 `arecall()` wall-clock latency + max asyncio event-loop stall (`loop.time()` delta).
3. **Migration Safety:** `0` overwritten 768-d/1536-d vectors when `EmbeddingEngine` transiently falls back to `hash`.
4. **Prompt Token Count:** Mean/max estimated tokens before vs. after `ContextBudgetManager` across 50 simulated turns.
5. **Authority & Mood Fidelity:** `100%` presence of `[CREATOR VERIFIED]` when `is_creator=True` across all providers + fallbacks; `temperature` delta within `[-0.15, +0.15]`.

---

## 3. Procedure

1. **Generate `MaybeAI-Memory-Bench-v1`:** Seed a temporary SQLite DB (`scratch/`) with 10,000 realistic VTuber episodes (including 30% aged target facts at rows 301–10,000) and 100 labeled queries.
2. **Benchmark Baseline vs. Variant A & B:** Measure `Recall@5`, `MRR@5`, p50/p95 `arecall()` latency, and startup/index-build time.
3. **Fault-Inject Dimension Mismatch:** Switch `embedding_provider` from `gemini` (768-d) to `hash` (128-d) mid-run and assert that existing 768-d rows are **skipped/preserved** (not overwritten) and no synchronous 300-call API storm occurs.
4. **Benchmark `ContextBudgetManager`:** Replay 50 multi-subsystem turns with 16-turn history + `character.lore` and verify token ceiling enforcement on 4K Ollama and 8K+ cloud profiles.

---

## 4. Go / No-Go Gate Criteria

| Metric | Baseline | Go Threshold |
|---|---|---|
| `Recall@5` on aged memories (`row > 300`) | `0.00` (invisible) | **`>= 0.75`** |
| `arecall()` p95 latency at `10,000` rows | Linear scan (capped at 300) | **`<= 15 ms`** |
| Event-loop block during `arecall()` | Sync SQLite on loop | **`<= 2 ms` loop jitter** (`asyncio.to_thread`) |
| Cloud vector overwrite on `hash` fallback | Overwrites DB (`[COG-HIGH-005]`) | **`0` overwrites** |
| Prompt token reduction (idle subsystems pruned) | Unbounded | **`>= 30%` token reduction** |
| `is_creator` & `MoodEngine` temp wiring | Dropped / dead code | **`100%` pass in `test_brain.py`** |

**Rollback / Fallback:** If `sqlite-vec` prebuilt wheels fail on a target Windows/Python 3.11 environment, promote **Variant B (`hnswlib` + FTS5 RRF)** or **NumPy matrix scan** (for `<10K` rows) while keeping `embedding_backend`/`embedding_dim` schema versioning and `ContextBudgetManager`.
