## 1. Problem & Hypothesis

### Problem (Verified in Post-H3 Audit)
1. **Flat Episodic-Only Storage & 2,000-Row Blind Spot:** `MemoryDatabase.vector_search()` scans at most `vector_scan_limit=2000` recent rows in a Python loop (`45.32 ms` measured at `N=2000`). Older memories are invisible to dense vector search, and `ContextMemory` only retains 16 turns plus a 4-snippet string-concatenated `rolling_summary`.
2. **Write-Only Reflection & Keyword Replanning:** `Goal.reflection` (`core/planning/replanner.py:35, 139`) is serialized to `goals.json`/`agenda.md` and never read by `GoalDecomposer` or `GoalEngine`. `StrategyReplanner` relies on static keyword matching (`"creeper"`, `"habis"`), causing repeated failed strategies across sessions.
3. **Unwired Promise Lifecycle:** `EpisodicMemoryStore.fulfill_promise()` and `archive_old_promises()` exist (`core/memory/__init__.py:105-114`) but are never called by `core/conversation/`, `core/planning/`, or `web/`.

### Hypothesis
If we introduce an **isolated, async off-peak Hierarchical Memory Consolidator** that:
1. Distills daily episodic clusters (`episodic_memories`) into compact **semantic facts** (`semantic_memories` table + `data/second_brain/` Markdown sync) and prunes/decays low-salience duplicates;
2. Replaces the `2,000`-row linear scan with **`sqlite-vec` (or `hnswlib` fallback) + FTS5 RRF** (`k=60`) offloaded via `asyncio.to_thread`;
3. Feeds `Goal.reflection` summaries into `GoalDecomposer` / `StrategyReplanner` and wires `fulfill_promise()` on goal/chat completion;

Then **aged-fact `Recall@5` (`row > 2000`) will reach `>= 0.80` in `<= 15 ms` p95 at `10,000` rows, and repeated failed strategies across a 10-goal benchmark will drop by `>= 25%`.**

## 2. Minimal Isolated Experimental Design

| Variant | Vector Index | Consolidation | Reflection & Promises |
|---|---|---|---|
| **Baseline (Control)** | Linear Python scan (`vector_scan_limit=2000`, `45.32 ms` measured) | None (flat episodes + 4-snippet `rolling_summary`) | `Goal.reflection` write-only; `fulfill_promise()` uncalled |
| **Treatment A (`sqlite-vec` + SLM Consolidator)** | `sqlite-vec` `vec0` + FTS5 RRF (`k=60`) | Off-peak batch distillation into `semantic_memories` (SLM/Flash-Lite) | `Goal.reflection` injected into `GoalDecomposer`; `fulfill_promise()` wired |
| **Treatment B (`hnswlib` Fallback)** | In-process `hnswlib` + FTS5 RRF (`k=60`) | Same | Same |

### Isolated Procedure
1. Seed a temporary `MemoryDatabase` (`10,000` synthetic episodes across 30 simulated stream days, 30% aged facts at indices `2,001..10,000`, plus 20 active promises).
2. Run Baseline vs. Treatment A/B across `100` labeled queries (`Recall@5`, `MRR@5`, `arecall()` p50/p95 ms) and `10` sequential `GoalEngine` missions with recurring failure modes.
3. Verify `Chaos D` invariant: inject 128-d `hash` fallback query against 384-d vectors and assert `0` overwrites.

## 3. Go / No-Go Gate Criteria

| Metric | Baseline (Observed) | Go Threshold (Target Estimate) |
|---|---|---|
| `arecall()` p95 @ `10,000` rows | `45.32 ms` @ `2,000` cap | **`<= 15 ms`** |
| `Recall@5` on aged facts (`row > 2,000`) | `0.00` (excluded by cap) | **`>= 0.80`** |
| Repeated failed strategies (10-goal bench) | Unmitigated (keyword-only) | **`>= 25%` reduction** |
| `promises.md` lifecycle closure | `0%` (unwired) | **`100%` fulfilled/archived in test** |
| `Chaos D` 384-d vector preservation | `100%` preserved | **`100%` preserved (`0` overwrites)** |

**Rollback:** Keep `vector_scan_limit=2000` + FTS5 as deterministic fallback if `sqlite-vec`/`hnswlib` fails to load on target OS.
